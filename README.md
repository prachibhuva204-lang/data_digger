# DataDigger 

# Project Overview

DataDigger is a MySQL-based E-Commerce Database Management System.
This project demonstrates how to create and manage customers, orders,
products, and order details using SQL.

# Database Name

DataDigger

# Tables

1. Customers
2. Orders
3. Products
4. OrderDetails

# Table Description

# 1. Customers
- Customer ID
- Customer Name
- Email
- Address

# 2. Orders
- Order ID
- Customer ID
- Order Date
- Total Amount

# 3. Products
- Product ID
- Product Name
- Price
- Stock

# 4. OrderDetails
- Order Detail ID
- Order ID
- Product ID
- Quantity
- SubTotal

# SQL Operations Performed

- Create Database
- Create Tables
- Insert Records
- Retrieve Records
- Update Records
- Delete Records
- Sort Products by Price
- Retrieve Orders by Customer
- Find Top 3 Most Ordered Products
- Count Product Sales
- Find Most Expensive Product

# Relationships
- Customers → Orders
- Orders → OrderDetails
- Products → OrderDetails

# Technologies Used

- MySQL
- MySQL Workbench
- SQL

# How to Run

1. Open MySQL Workbench.
2. Open the `DataDigger.sql` file.
3. Refresh the Schemas section.
4. Open the `DataDigger` database.
5. Check the four tables under Tables.
